## 🏔️ About Glacier Software

**Glacier Software** is a high-performance, bare-metal C# .NET 10 ecosystem designed to challenge the status quo in high-performance computing, data analytics, and artificial intelligence:

- **[Glacier.Polaris](https://github.com/ian-cowley/Glacier.Polaris)** — SIMD-accelerated columnar DataFrame engine for .NET 10 (100% parity with Polars).
- **[Glacier.Forge](https://github.com/ian-cowley/Glacier.Forge)** — Zero-allocation high-throughput JSONL ingestion engine for SQL Server & PostgreSQL.
- **[Glacier.Inference](https://github.com/ian-cowley/Glacier.Inference)** — Bare-metal pure C# LLM & MoE engine with Direct3D 12 and zero native C++ dependencies.
- **[Glacier.Studio](https://github.com/ian-cowley/Glacier.Studio)** — Autonomous desktop AI agent IDE and distributed cluster cockpit.
- **[Glacier.Cluster](https://github.com/ian-cowley/Glacier.Cluster)** — Distributed compute fabric and zero-copy Arrow IPC collective engine.
- *...and 25+ more purpose-built high-performance libraries.*
